# Mi primer repositorio

Proyecto académico para aprender los conceptos básicos de GitHub y documentar mi progreso.

## Objetivos

- Crear y organizar archivos.
- Registrar cambios mediante commits.
- Practicar con ramas y pull requests.
- Escribir documentación en Markdown.

## Cómo usar este repositorio

Explora los archivos, realiza un cambio pequeño y guárdalo con un commit que explique qué modificaste.

## Ejercicio inicial

1. Crea un archivo llamado `aprendizajes.md`.
2. Escribe tres cosas que hayas aprendido sobre GitHub.
3. Guarda los cambios con el mensaje: `Agrega primeros aprendizajes`.

## Estado

En desarrollo como parte de un proceso de aprendizaje.
